# Upstream compatibility

Primary reference: `RfidResearchGroup/proxmark3` (Iceman fork).

The application does not embed the upstream C client. It consumes documented output and dump formats. Record the exact installed upstream commit with:

```text
UTAMO_PM3_UPSTREAM_COMMIT=<commit hash or release tag>
```

After updating Proxmark3:

1. run `hw version` and retain the parsed version record;
2. run `python tools/validate_pm3_catalog.py <checkout>/doc/commands.md`;
3. run `pytest -q`;
4. import sanitized fixtures generated by the new client;
5. verify read-only commands on physical hardware.

`Gator96100/ProxSpace` remains an external Windows build environment. It is not copied into this application. Point the Utamo configuration to the client built or installed through that environment.
