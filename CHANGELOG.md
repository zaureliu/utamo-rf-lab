# Changelog

## 3.2.0

### Security and hardening
- Strict production configuration validation, trusted-host/proxy settings and explicit remote-bind opt-in.
- Bounded, thread-safe login throttling with `Retry-After` responses.
- Strengthened browser headers; strict CSP without inline script/style execution.
- Hardened environment parsing and API numeric validation.
- CSV formula-injection protection in exported reports.
- Operator-paste provenance: manually pasted output is labeled `operator_paste` instead of being reported as device output.

### Parser and import stabilization
- Invalid or malformed dumps now return structured 400 responses instead of server errors.
- Smart-scan jobs that fail before execution are marked as failed instead of remaining pending.

### Reliability
- Hermetic test bootstrap (isolated runtime directory) so local runs and CI behave identically without hardware.
- Serialized smart-scan polling, cancellation on page exit and retry backoff in the browser.
- Hardwareless operation: full startup, login, offline analysis and sessions work with no Proxmark3 connected.

### Interface
- Rebuilt responsive layout and stylesheet with consistent components, focus visibility and reduced motion.
- Simplified global navigation and reduced visual weight across pages.
- All behaviors/styles moved into local static assets; no inline scripts or styles.

### Repository
- Removed dormant RF/SDR experiment modules and obsolete interface assets from the tree.
- Generated bytecode, databases, dumps, captures and reports excluded from version control while preserving local files.
- CI on Python 3.11–3.14 with pytest, Ruff security/quality checks and a tracked-content secret audit.
